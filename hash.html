hashlib SHA-256 코드 상세 설명

비밀번호 해시 저장 원리를 파이썬 코드로 이해하기

1. 전체 코드

import hashlib

password = "safe1234"
hashed = hashlib.sha256(password.encode()).hexdigest()

print("원본 비밀번호:", password)
print("해시 길이:", len(hashed))
print("동일 여부:", hashed == hashlib.sha256("safe1234".encode()).hexdigest())

2. 한 줄씩 상세 설명

import hashlib
모듈 불러오기

파이썬의 hashlib 모듈을 가져옵니다. 이 모듈은 SHA-256 같은 해시 함수를 사용할 때 필요합니다.

password = "safe1234"
비밀번호 저장

문자열 "safe1234"를 변수 password에 저장합니다. 여기서는 사용자가 입력한 비밀번호라고 생각하면 됩니다.

hashed = hashlib.sha256(password.encode()).hexdigest()
해시 생성

비밀번호를 SHA-256 방식으로 해시합니다.

  • password.encode(): 문자열을 바이트 형태로 변환합니다.
  • hashlib.sha256(...): SHA-256 해시 함수에 넣습니다.
  • .hexdigest(): 결과를 16진수 문자열로 바꿉니다.
print("원본 비밀번호:", password)
원본 출력

변수 password에 저장된 원본 비밀번호를 출력합니다.

print("해시 길이:", len(hashed))
길이 확인

len(hashed)는 해시된 문자열의 길이를 구합니다. SHA-256의 16진수 결과는 항상 64글자입니다.

print("동일 여부:", hashed == hashlib.sha256("safe1234".encode()).hexdigest())
해시 비교

처음 만든 해시값과 "safe1234"를 다시 해시한 값이 같은지 비교합니다. 같은 입력값을 같은 해시 함수로 처리하면 항상 같은 결과가 나오므로 True가 출력됩니다.

3. 실행 결과

원본 비밀번호: safe1234
해시 길이: 64
동일 여부: True

4. 핵심 개념 정리

개념 설명
해시 입력 데이터를 고정된 길이의 문자열로 바꾸는 과정입니다.
SHA-256 해시 알고리즘 중 하나이며, 결과가 256비트입니다.
encode() 문자열을 바이트 데이터로 변환합니다.
hexdigest() 해시 결과를 16진수 문자열 형태로 바꿉니다.

5. 보안상 중요한 점

실제 서비스에서는 비밀번호를 단순히 SHA-256으로만 저장하지 않는 것이 좋습니다. 보안을 높이기 위해 salt를 추가하거나 bcrypt, scrypt, argon2 같은 비밀번호 저장 전용 알고리즘을 사용하는 것이 좋습니다.
